# Mechanism AI — толық бастапқы жоба

## Құрамы
- `bot.py` — Telegram бот және HTTPS хостингке арналған веб-серверді бірге іске қосады.
- `web/index.html` — Telegram Mini App ішіндегі интерактивті кинематикалық модель.
- `render.yaml` — Render-ге орналастыру үлгісі.

## Қазір жұмыс істейтін мүмкіндіктер
- `/start` мәзірі және `/help` нұсқаулығы.
- Қолданушы механизм атауын жазса, Mini App ашатын батырма алады.
- Автоматты режим: мәтіндегі атау бойынша қолжетімді үлгіні таңдайды (төрт буынды немесе иінді-сырғақты).
- Параметрлік режим: иін, жалғастырғыш, тіректер арасы және бастапқы бұрыш мәндерін өзгерту.
- Қозғалысты бастау/тоқтату, бағытын ауыстыру, бұрышты қолмен өзгерту.
- Қозғалыс траекториясын көрсету.

## Қазіргі шектеулер
Бұл нұсқа — жұмыс істейтін MVP, бірақ «кез келген машинаны» толық AI арқылы жобаламайды. Автоматты режим қазір мәтіннен екі дайын кинематикалық үлгінің бірін таңдайды. Төрт буынды модельдің геометриялық өлшемдері демонстрациялық әдепкі мәндермен берілген; күрделі геометрияда жинақталу шарттарын қосымша тексеру қажет. Бұл құрал өндірістік жобалау немесе қауіпсіздік сертификатының орнына жүрмейді.

## Telegram ботты іске қосу

### 1. Бот ашу
1. Telegram-нан `@BotFather` аш.
2. `/newbot` командасын жібер.
3. Бот атауын `Mechanism AI` деп енгіз.
4. Username таңда (соңы `bot` болып бітуі керек), мысалы `MechanismAI_demo_bot` — бос болмауы мүмкін.
5. BotFather берген токенді құпия сақта. Оны ешкімге жіберме және GitHub-қа салма.

### 2. Render-ге орналастыру
1. Осы ZIP ішін GitHub репозиторийіне жүкте.
2. Render аккаунтына кіріп, New → Blueprint арқылы репозиторийді таңда.
3. Render сервис жасағанда `BOT_TOKEN` мәніне BotFather токенін енгіз.
4. Қызмет жарияланғаннан кейін Render берген HTTPS адресін көшір.
5. Render Environment ішіндегі `PUBLIC_URL` мәніне сол HTTPS адресін енгіз. Өзгерісті сақтап, қайта deploy жаса.
6. Telegram-да ботқа `/start` жіберіп тексер.

`PUBLIC_URL` міндетті түрде `https://` адресі болуы керек. Mini App HTTP сілтемесімен ашылмайды.

### 3. Компьютерде жергілікті сынау
Python 3.10+ орнат:
```bash
pip install -r requirements.txt
```
Linux/macOS:
```bash
export BOT_TOKEN="BOTFATHER_TOKEN"
export PUBLIC_URL="https://your-public-domain.example"
python bot.py
```
Windows PowerShell:
```powershell
$env:BOT_TOKEN="BOTFATHER_TOKEN"
$env:PUBLIC_URL="https://your-public-domain.example"
python bot.py
```

Жергілікті компьютердің `localhost` адресі Telegram Mini App үшін жарамсыз; сыртқа ашық HTTPS домен керек.

## Қауіпсіздік
- Токенді кодқа жазба; тек Environment Variables арқылы бер.
- Токен жария болып кетсе, BotFather арқылы жаңасын жаса.
- Тегін хостинг ұйқы режиміне кетуі мүмкін; тұрақты қолжетімділік үшін ақылы хостинг қажет болуы ықтимал.

## Келесі кәсіби даму кезеңдері
- AI API арқылы еркін мәтінді талдау және түсінбеген сұранысты нақтылау.
- Параметрлерге арналған математикалық жарамдылық тексерістері.
- Three.js арқылы 3D модель, бөлшектерді айналдыру/жақындату.
- Көп буынды механизмдер кітапханасы және есеп беру PDF.
- Механизмнің нақты кинематикалық теңдеулері мен графиктері.
